# تحويل Sky Sudan لتطبيق حقيقي في Google Play و App Store

المشروع ده مبني بحيث تقدر تاخده لمتجر التطبيقات باستخدام أداة اسمها **Capacitor** — بتاخد موقعك زي ما هو وتحوّله لتطبيق أندرويد/آيفون حقيقي بدون ما تعيد كتابة الكود.

## قبل ما تبدأ — لازم يكون عندك:

| المطلوب | ليه محتاجه |
|---|---|
| Node.js (نسخة 18+) | لتشغيل المشروع |
| **Android Studio** | لبناء تطبيق أندرويد (مجاني) |
| **جهاز Mac + Xcode** | لبناء تطبيق آيفون (Apple ما بتسمحش ببناء iOS من غير Mac) |
| حساب Google Play Console | **25$ مرة واحدة بس** لنشر تطبيقات أندرويد |
| حساب Apple Developer | **99$ سنويًا** لنشر تطبيقات آيفون |

لو معندكش Mac ومحتاج تطبيق آيفون، فيه خدمات بتأجرك Mac أونلاين بالساعة (زي MacinCloud) بدل ما تشتري جهاز.

## الخطوات

### 1. ثبّت المكتبات
```bash
cd sky-sudan-project
npm install
```

### 2. اعمل بناء (build) لموقعك
```bash
npm run build
```
ده بينتج مجلد `dist` فيه نسخة نهائية من الموقع.

### 3. أضف منصة أندرويد و/أو iOS
```bash
npx cap add android
npx cap add ios
```
(تقدر تعمل واحدة بس لو مش محتاج التانية دلوقتي)

### 4. زامن الكود مع المشروع الأصلي
```bash
npx cap sync
```
شغّل الأمر ده تاني كل مرة تعدّل في الكود وتعمل `npm run build` جديد.

### 5. افتح المشروع في Android Studio
```bash
npx cap open android
```
هيفتح Android Studio تلقائيًا. من جواه:
- اختار **Build > Generate Signed Bundle / APK**
- اعمل مفتاح توقيع جديد (Keystore) — **احتفظ بيه في مكان آمن، لو ضاع مش هتقدر تحدّث التطبيق تاني**
- اختار **Android App Bundle (AAB)** وده اللي بيتقبل في Google Play

### 6. ارفعه على Google Play Console
- روح على [play.google.com/console](https://play.google.com/console)
- ادفع رسوم التسجيل (25$ مرة واحدة)
- اعمل تطبيق جديد، ارفع ملف الـ AAB، أضف السكرين شوتس والوصف
- قدّمه للمراجعة (بتاخد من ساعات لحد كام يوم)

### 7. لتطبيق آيفون (لو عندك Mac)
```bash
npx cap open ios
```
هيفتح Xcode. من جواه: **Product > Archive**، بعدين ارفعه لـ App Store Connect من نفس الويزارد، وكمّل التقديم من [appstoreconnect.apple.com](https://appstoreconnect.apple.com).

## ملاحظات مهمة

- **أيقونة التطبيق**: حطّيت لك أيقونة مبدئية في `public/icons/` — استبدلها بأيقونة نهائية بتصميمك قبل النشر (المتاجر بترفض الأيقونات المؤقتة أحيانًا).
- **اسم الحزمة (Package ID)**: حاليًا `com.skysudan.app` في ملف `capacitor.config.ts` — غيّره لاسم فريد بتاعك لو حابب قبل النشر.
- **البيانات لسه تجريبية (Mock)**: التطبيق شغال بس ببيانات وهمية. لازم تربطه بـ API حقيقي (شرحته في ملف `src/App.jsx` جوه المتغيّر `api`) قبل ما تنشره فعليًا للمستخدمين.
- المتاجر (خصوصًا Apple) بتراجع التطبيقات وبترفض أي تطبيق فيه بيانات وهمية أو وظائف ناقصة — لازم يكون شغال بشكل حقيقي وكامل قبل التقديم.

## بديل أسرع: تطبيق PWA (بدون متجر)

لو حابب حل أسرع وبدون رسوم أو انتظار مراجعة، أقدر أظبطلك المشروع كـ PWA — المستخدم بيدخل الرابط من المتصفح ويضغط "إضافة للشاشة الرئيسية" ويشتغل زي تطبيق عادي، بدون Google Play ولا App Store. قولّي لو عايز ده كمان.
