# Sky Sudan

نسخة تجريبية متكاملة لنظام حجز وإدارة رحلات Sky Sudan، بواجهة عربية RTL.

## الموجود في المشروع
- الصفحة الرئيسية والبحث عن الرحلات
- نتائج الرحلات وتفاصيل الرحلة
- اختيار المقاعد وبيانات المسافرين
- الدفع التجريبي والتذكرة الإلكترونية
- تسجيل الدخول وإنشاء الحساب
- لوحة المستخدم
- لوحة الإدارة: الرحلات، الحجوزات، المستخدمون، المسافرون، التقارير والإعدادات
- دعم Supabase عند إضافة مفاتيح البيئة، مع وضع Demo تلقائي بدون قاعدة بيانات
- إعداد Capacitor لتحويل الواجهة إلى تطبيق Android/iOS لاحقًا

## التشغيل على Windows 11 / VS Code
1. ثبّت Node.js 18 أو أحدث.
2. افتح مجلد المشروع في VS Code.
3. افتح Terminal واكتب: `npm install`
4. بعد اكتمال التثبيت اكتب: `npm run dev`
5. افتح العنوان المحلي الذي يظهر في Terminal.

## قاعدة البيانات
انسخ `.env.example` إلى `.env` وأضف بيانات Supabase، ثم نفّذ `supabase-schema.sql` داخل SQL Editor في Supabase. بدون ذلك سيعمل المشروع في وضع Demo محليًا.
